# 0.50.0 - 2026-09-07

[Compare with 0.49.0](https://github.com/milisp/codexia/compare/v0.49.0...v0.50.0)

## Added

- Bot tab with Keke-backed chats: list sessions, start new ones from the sidebar, pick workspace folder via Tauri file dialog, and configure provider/model through the ACP menu (`9df8eba6`, `08faba36`, `ff45abb6`, `ddbd4f2a`, `dd7f01cc`, `5297b056`).
- Toast deduplication to prevent duplicate notifications stacking up (`ad37fe24`).
- Web server now supports configuring extra CORS origins (`91f8ee26`).
- Local file assets are now served over HTTP through the loopback web server (`ba6bf560`).

## Changed

- Routed all remaining desktop and filesystem calls through the loopback web server (`844044e0`, `80c69b36`).
- Bot conversations are now scoped to each bot individually (`3422c5d2`).
- Bot settings dialog opens automatically after creating a new bot (`dd7f01cc`).
- `src-tauri/Cargo.toml` license updated to MIT (`8ab8c6f3`).

## Fixed

- Empty bot sessions no longer accumulate across restarts (`d0937471`).
- Fixed close button clipping on toast notifications (`ad37fe24`).
- Dev browser now opens only after the web server actually binds (`ede72722`).
- Git diff now detects binary files and skips text diffing for them (`37d88710`).
- Removed `noVoid` lint warnings in `BotSessionList` (`f2616a73`).
