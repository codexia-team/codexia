# 0.49.0 - 2026-09-01

[Compare with 0.48.2](https://github.com/milisp/codexia/compare/v0.48.2...v0.49.0)

## Added

- File explorer now renders PDF, XLSX, and DOCX files directly in the frontend (`b449c2c3`).
- PPTX preview renders actual slide thumbnails via `pptx-preview`, replacing the previous "not supported" message, with a slide thumbnail rail added for navigation (`90a58fd2`, `a43a96b3`).

## Changed

- Replaced the Radix UI toast implementation with sonner for improved toast management (`5741f4cb`).
- justfile now uses cargo watch for automatic backend recompilation (`15119240`).

## Fixed

- Fixed the debounce ref type in hooks to use `ReturnType<typeof setTimeout>` (`ca0b8bfa`).
